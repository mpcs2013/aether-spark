# ADR-0001: Record architecture decisions
- **Status:** Accepted · **Date:** 2026-10-03
## Context
A solo-built platform with long horizon needs traceable reasoning behind its choices.
## Decision
Use lightweight ADRs (template 0000) in `docs/adr/`. One decision per file, immutable once Accepted; changes via a superseding ADR.
## Consequences
Small writing overhead; AI agents working in the repo get authoritative context.
